> **Instrucción de diseño:** Este documento es el contenido y layout para un flyer imprimible en **una sola hoja tamaño carta** (doble cara). Usar colores Heinz (rojo #C8102E, blanco, gris oscuro). ```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  PREGUNTA 1: ¿Qué VENDE principalmente?                     │
│  → Si es algo específico (pan, carne, medicinas, licores)    │
│    = Usa ese segmento especializado                          │
│  → Si vende de todo = sigue a la pregunta 2                  │
│                                                              │
│  PREGUNTA 2: ¿El cliente se SIRVE SOLO o le DESPACHAN?       │

│  → Muy pequeño (< 30 m²) = BODEGA                           │
│  → Pequeño-Mediano (30-80 m²) = ABASTO                      │
│  → Mediano-Grande con pasillos = SUPERMERCADO                │
│                                                              │

## Especificaciones para el Diseñador Gráfico

| Elemento | Especificación |
|---|---|
| Tamaño | Carta (8.5" × 11"), doble cara |
| Orientación | Vertical (portrait) |
| Colores primarios | Rojo Heinz #C8102E, Blanco, Gris oscuro #333333 |
| Colores de apoyo | Verde #28A745 (correcto), Amarillo #FFC107 (alerta), Azul #007BFF (info) |
| Tipografía | Calibri o Montserrat, tamaños 10-18pt |
| Iconos | Reemplazar emojis por iconos flat de un solo color (estilo Flaticon/Material) |
| Tarjetas de segmento | Esquinas redondeadas, sombra sutil, icono arriba, texto abajo |
| Impresión | CMYK, 300 DPI, sangrado 3mm |
| Laminado | Recomendado (uso frecuente en campo) |
